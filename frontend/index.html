      Document Q&A
      No network required

      Ask a question. Every claim in the answer comes back marked with the passage it came from.

      Text extraction, embeddings, retrieval and generation all run on this machine. Answers cite their sources by document and page, and when the retrieved passages don't support an answer, you get told that instead of a guess.

      1. 01 Add a PDF, DOCX, TXT or Markdown file. Text extraction, chunking and embedding run in the background — the upload returns straight away.
      2. 02 Wait for the status dot to turn green. Until then the document isn't searchable yet.
      3. 03 Ask away. Tick documents in the library to narrow the search, or leave them all unticked to search everything.
